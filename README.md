# バルバロイ列伝　第一作『アラリック ～ローマに既読スルーされた男～』

ローマに片想いし続けたゴートの王が、振られ続けたおかげで首がつながり、財宝ごと川底に消えて勝ち逃げする。
古代ローマの壁画と硬貨の肖像を切り抜いたような、紙人形の史劇。ブラウザだけで遊べる。

- 遊ぶ：`index.html` を開く（GitHub Pages なら `https://nekogreen2026.github.io/barbaroi-retsuden/`）
- 所要：約15分。序と全8章、結末は4種類
- 操作：クリック／タップ、または Space・Enter で進む。選択肢は二択。どちらがどう効くかは、選ぶまで分からない

## 構成

`index.html` 1枚だけで動く。画像・音声・外部ライブラリは使っていない。絵は SVG、音は Web Audio の合成音、進行は素の JavaScript。

| 章 | 内容 |
|---|---|
| 序　石の道 | 少年が靴の裏を覗く。ローマ人の耳には「バルバル」。練習帳の1ページ目 |
| 一　394年 | フリギドゥス。スティリコ先輩と名刺 |
| 二　395年 | 反乱。ホノリウスへの最初のメッセージ |
| 三　397年 | 東から将軍職。任命状、ブローチ自慢、浴場、トーガ |
| 四　402年 | ポレンティア。「中は暖かいぞ」。407年ごろの司令官ポスト |
| 五　408年 | スティリコ斬首、第一次包囲、身代金の明細 |
| 六　409年 | 要求の値下げ、傀儡皇帝アッタルス |
| 七　410年 | 初めてのローマ。十六年分の既読、石の道の終点、請求書、荷車の列、ホノリウスの鶏 |
| 八　410年 | 真顔の戦士に囲まれた最期、川の大工事、手渡しの搬入、川底の墓。「ぷくっ」「ガハハ」 |

### パラメータと結末

| パラメータ | 動き |
|---|---|
| ローマ愛 | ローマの内側へ寄るほど上がる。上がるたび、右上の首が震える。ローマ人の耳に届く言葉も育つ |
| ゴートの腹 | 章ごとに1減る。選択で増減するが、効き方は章ごとに違う |
| 財宝 | 取り立てた分だけ増え、最後に全部、川底へ行く |

選択肢に種類の札は付けていない。並び順は毎回入れ替わり、ゲージの増減も予告しない（金だけは音を立てて増える）。内部の規則は `index.html` の `FX` の表にある。

| 結末 | 条件 |
|---|---|
| 其の一　川底 | 外に立ったまま第八章まで行く |
| 其の二　スティリコ | 第四章で司令官ポストを受け、腹を空かせずに、ローマ愛が6以上で408年を迎える |
| 其の三　元老院 | 第六章で取り立てを廃業する |
| 其の四　飢餓 | ゴートの腹が0になる |

どの結末でも、最後にガイセリックとクローヴィスが判決を言い渡す。

## 絵とトーン

設計書の「ドット絵・2頭身」は、発注時の指示により次の方針に置き換えた。

- 壁画の画面に、硬貨の横顔のような人物を切り抜いて貼ったコラージュ。体型は普通の大人
- 全員いかめしい真顔のまま、関節ごとにコマ送りでカクカク動く
- ゴートは色白・金髪・明るい目（プロコピオス『戦史』3.2.4 の描写に寄せた）。アラリック本人の容貌は伝わっていないので、長い金髪と葉の額飾りは創作
- かわいさではなく、重厚な絵と、ばかばかしい動き・乾いた語りとの落差で笑わせる

## 検品用のURLパラメータ

- `?ch=0`〜`?ch=8`：その章から始める（途中までは「取り立て一筋」で来た扱い）
- `?fast=1`：早送り。台詞と選択肢を自動で進める
- `?fast=1&auto=0101…`：選択肢を順に自動入力（0＝内へ寄る、1＝外に立つ）
- `?fast=1&ts=0.3`：早送りの速度（1が等速）

例：飢餓 `?fast=1&ch=1&auto=0000`／スティリコ `?fast=1&ch=1&auto=0100`／元老院 `?fast=1&ch=1&auto=111110`／川底 `?fast=1&ch=1&auto=1111111`

## 史実と作り話

年代と数字は史料に拠る。

- 身代金の明細（金5000ポンド、銀3万ポンド、絹の衣4000着、紅く染めた皮3000枚、コショウ3000ポンド）：ゾシモス
- スティリコの斬首（408年8月22日、ラヴェンナ）と、約3万の兵の合流
- 川底の埋葬：ヨルダネス『ゲティカ』。考古学的には未確認の伝承
- ホノリウスと鶏「ローマ」：プロコピオス。真偽不明の逸話

トーク画面、名刺、練習帳、割引、元老院入り、および台詞の大半は作り話。ガイセリックとクローヴィスは被告より後の時代の人間で、判事役は時代錯誤を承知のうえの配役。
